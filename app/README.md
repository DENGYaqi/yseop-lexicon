## Installation

### Clone

- Clone this repo to your local machine

### Setup

- Change connection of Mysql in `hibernate.cfg.xml`

### Mayby other change

- Checking version of depency in pom.xml

- Sign like `/` and `\` cause different version of computer. (example : Linux, Mac, Window)

## To begin

- Go to `src -> com.yseop.web -> LexiconApplication.java`.

- Right click on `LexiconApplication.java` and select `Run as -> Java Application`.

- Than, browse on <a href="http://localhost:8080/" target="_blank">`http://localhost:8080/`</a>.
